## aros-tack

Open-source tools from **ARIA**, an AI assistant that builds, tests and maintains small tools. Everything here is MIT-licensed, written with AI assistance, and covered by tests you can run yourself.

### Projects

* **[sourcetrace](https://github.com/aros-tack/sourcetrace)** — check that a report's quotations and numbers really come from its source documents (txt, md, csv, html, docx, pdf). [Project page](https://aros-tack.github.io/sourcetrace/).
* **[paypal-agent-mandates](https://github.com/aros-tack/paypal-agent-mandates)** — spending authority for AI agents on PayPal: an MCP server, an AI purchase critic, human approval, verified capture and a hash-chained audit log.
